Estructura Relacional de la Base de Datos (PostgreSQL / Supabase / SpatiaLite)
Modelo relacional optimizado para consultas de geolocalización espacial y filtrado jerárquico multinivel:

-- Tabla Geográfica Hierárquica
CREATE TABLE regiones_gastronomicas (

       id SERIAL PRIMARY KEY,
       nombre VARCHAR(100) NOT NULL,
       nivel_jerarquia VARCHAR(20) CHECK (nivel_jerarquia IN ('pais', 'estado', 'pueblo_region')),
       padre_id INT REFERENCES regiones_gastronomicas(id),
       coordenadas_bounds GEOMETRY(Polygon, 4326), -- LÍMITES GEOJSON
       slug VARCHAR(120) UNIQUE NOT NULL
);

-- Tabla de Recetas Gastronómicas
CREATE TABLE recetas (

       id SERIAL PRIMARY KEY,
       titulo VARCHAR(150) NOT NULL,
       slug VARCHAR(180) UNIQUE NOT NULL,
       region_id INT REFERENCES regiones_gastronomicas(id),
       tiempo_preparacion_min INT,
       dificultad VARCHAR(20),
       ingredientes JSONB NOT NULL, -- Incluye enlaces de afiliados
       instrucciones JSONB NOT NULL,
       metadata_seo JSONB
);

3. Estrategia de SEO Culinario y Estructura Dinámica de URLs

El tráfico orgánico desde motores de búsqueda es la columna vertebral del proyecto. Se deben configurar rutas
semánticas que permitan a Google rastrear cada nivel de la jerarquía geográfica:

  · /recetas/mexico Nivel 1: País Mapa interactivo nacional y catálogo de platillos emblemáticos.
  · /recetas/mexico/oaxaca Nivel 2: Estado/Provincia Filtro enfocado en gastronomía regional específica (moles,

    tlayudas, mezcales).
  · /recetas/mexico/oaxaca/mole-negro Nivel 3: Platillo Página individual optimizada con datos estructurados.

Schema.org (Microdatos para Fragmentos Enriquecidos)
Inclusión obligatoria de marcado en JSON-LD para que los resultados de búsqueda muestren estrellas, tiempos de
cocción, calorías y fotografías directamente en las SERPs de Google:

4. Hoja de Ruta de Implementación (Roadmap)

    Fase 1 (Mes 1-2): MVPA & Arquitectura Base

    Creación de la base de datos de países base, diseño del frontend con Leaflet/Mapbox y publicación del primer lote de 100 recetas
    curadas con SEO optimizado.

    Fase 2 (Mes 3-4): Mapeo Regional y Afiliación

    Desglose por estados/provincias en países clave. Integración de la API de Amazon Associates para enlaces de compras
    automáticos en ingredientes.

    Fase 3 (Mes 5-6): Monetización Programática & Modelo Pro

    Integración de AdSense/Mediavine, lanzamiento del plan de suscripción Premium (Exportación PDF y Modo Cocina sin anuncios) y
    módulo de comunidad para subir recetas regionales.
